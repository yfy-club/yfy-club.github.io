### 标题与段落排版

Markdown 使用井号 `#` 声明各级标题，井号数量对应标题级别（1 到 6 级）：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

#### 段落与换行规则

* **普通段落**：前后保留一个空行即可自动识别为一个独立段落；
* **硬换行**：在行尾连续敲入两个空格再按回车，或在行间插入空行。

### 文本修饰与字体样式

通过特定的符号包裹文本，可以快速实现加粗、斜体与行内等宽代码：

| 语法格式 | 视觉效果 | 适用场景 |
|---|---|---|
| `**粗体文本**` | **粗体文本** | 强调关键术语与重点说明 |
| `*斜体文本*` | *斜体文本* | 次要提示或专有名词 |
| `***粗斜体***` | ***粗斜体*** | 极高强度强调 |
| `~~删除线文本~~` | ~~删除线文本~~ | 废弃接口或已过时方案 |
| `` `const a = 1;` `` | `const a = 1;` | 行内变量名、函数名与文件路径 |

### 列表排版语法

Markdown 支持无序列表、有序列表以及待办任务复选列表。

#### 1. 无序列表与有序列表

```markdown
<!-- 无序列表：使用减号 - 或星号 * 开头，后跟一个空格 -->
- 计算机组成原理
- 操作系统调度
- 计算机网络

<!-- 有序列表：使用数字加英文句号 . 开头 -->
1. 需求分析与接口设计
2. 本地编码与单元测试
3. 发起合并请求与评审
```

#### 2. 待办任务清单

```markdown
- [x] 已完成 JDK 与 Git 环境配置
- [x] 已跑通本地第一个 Hello World 程序
- [ ] 待完成大作业核心业务逻辑开发
```

### 引用与多语言代码块

#### 1. 引用区块

使用大于号 `>` 开头表示引用，支持多层嵌套：

```markdown
> 这是一个一级引用块
> 
>> 这是一个嵌套的二级引用块，用于放置辅助注解
```

#### 2. 多语言代码块

使用三反引号包裹代码，并在开头指定语言标识（如 `java`、`ts`、`c`、`sql`、`bash`）以获得精准的语法高亮：

```java
public class HelloMarkdown {
    public static void main(String[] args) {
        System.out.println("Hello, Markdown!");
    }
}
```

### 超链接、图片与表格

#### 1. 超链接与图片语法

```markdown
<!-- 1. 超链接：[链接文字](目标URL) -->
[访问云飞扬社团主页](https://yfy-club.github.io)

<!-- 2. 图片：![替代文本](图片路径或URL) -->
![社团徽标](https://yfy-club.github.io/logo.png)
```

#### 2. 表格与文本对齐语法

使用竖线 `|` 分隔列，使用横线 `-` 分隔表头与内容；在横线两侧添加冒号 `:` 可控制对齐方式：

```markdown
| 左对齐（默认） | 居中对齐 | 右对齐（数值） |
|:---|:---:|---:|
| 商品名称 | 规格型号 | 单价（元） |
| 机械键盘 | 红轴 87 键 | 299.00 |
| 显示器支架 | 双臂气压款 | 159.00 |
```

### 分割线与转义字符

* **水平分割线**：使用三个或更多连字符 `---` 或星号 `***` 单独成行。
* **特殊字符转义**：如果需要在正文中显示 Markdown 保留符号（如 `*`、`#`、`_`），在符号前加反斜杠 `\` 转义（例如 `\*不倾斜\*`）。

### 阶段实战大作业

使用 Markdown 编写一份完整的个人技术简历或项目 `README.md`：
1. 包含各级标题与项目技术栈徽标/列表；
2. 包含一个多语言代码块展示核心算法或核心类；
3. 包含一张表格展示项目模块分工与完成状态。
