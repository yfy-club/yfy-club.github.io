### 大三分流双轨规划

进入大三阶段后，依据个人长远目标进入专业化发展分支：

```
           ┌─── 就业方向：微服务架构、高并发中间件与分布式工程
大三分流 ──┤
           └─── 考研方向：计算机 408 核心专业课、科研与学科竞赛
```

### 就业工程分支：微服务与高并发中间件

持续深耕主流企业级高并发架构体系：

* **微服务治理**：Spring Boot 与 Spring Cloud 服务注册发现、网关路由与分布式配置管理；
* **Redis 分布式缓存**：深入理解缓存穿透（布隆过滤器与空值缓存）、击穿（互斥锁与逻辑过期）、雪崩（随机 TTL）应对策略；掌握基于 Redisson 的分布式锁实现与看门狗自动续期机制；
* **RabbitMQ 消息中间件**：掌握生产者确认机制、消费者手动确认（ACK）、死信队列处理以及基于唯一消息 ID 的幂等消费设计；
* **安全与鉴权体系**：掌握 Spring Security 框架、JWT 无状态令牌认证与基于角色的访问控制（RBAC）模型。

### 考研深造分支：计算机 408 核心课攻坚

系统攻坚全国统考计算机学科专业基础（408）四门核心课程：

* **数据结构**：深入树与图的高级算法（Dijkstra 最短路径、Kruskal 最小生成树、拓扑排序）及经典内部排序算法；
* **计算机组成原理**：IEEE 754 浮点数表示、流水线冲突与冒险、Cache-主存组相联映射机制及 TLB 快表寻址；
* **操作系统**：进程线程状态流转与死锁避免（银行家算法）、虚拟内存分页置换（LRU/FIFO）与文件系统 Inode 索引结构；
* **计算机网络**：TCP 三次握手与四次挥手状态机、拥塞控制算法（慢启动、拥塞避免、快重传、快恢复）以及 HTTPS TLS 握手握签原理。

### 资料共享打卡与科研竞赛赋能

建立社团内部考研资料共享库与真题交流圈，推行每日学习打卡与定期模拟研讨机制，促进跨年级经验传承。

引导有志深造的成员参与深度学习、机器视觉等科研与学科竞赛课题（如光伏板缺陷智能检测），产出学术成果与工程原型，为研究生初试复试积累扎实背景。
