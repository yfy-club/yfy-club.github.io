### 核心背景与技术定位

第一周的目标不是写出多少代码，而是跑通一次完整的工程循环：从克隆仓库到发起合并请求。这条路径走通了，之后每一次开发都是它的重复与扩展；走不通，后面的每个任务都会在同一个地方卡住。本篇按天拆解这条路径。

#### 提问的姿势

卡住超过一小时就该提问，但提问前先完成三步自查：重读报错信息全文、搜关键词、查本篇与《高频故障排查手册》。提问时给出现象、已尝试的步骤与完整报错——「报错了」三个字得不到任何帮助。

### 项目初始化四步

#### 第一步：克隆与结构速览

```bash
# 克隆到固定工作目录，路径不含空格与中文
git clone https://github.com/yfy-club/example-project.git
cd example-project

# 先读三份文件再动手：说明、贡献指引与目录结构
cat README.md
```

速览目录结构时只回答三个问题：代码在哪、测试在哪、构建命令在哪。其余细节用到再查。

#### 第二步：依赖安装

```bash
# 按锁文件精确安装，拒绝随手 install
npm ci

# 安装失败先看报错首行：缺系统依赖、镜像超时、版本不符是三大类
```

#### 第三步：环境变量本地配置

仓库里的示例环境文件复制为本地环境文件，本地文件永远不进版本库：

```bash
# 从示例复制出本地配置，再按说明逐项填写
cp .env.example .env.local
```

```json
{
  "说明": "示例环境文件的典型结构，本地填写真实值",
  "API_BASE": "http://localhost:8080",
  "DEBUG": "true",
  "TOKEN": "向师傅申请开发令牌，严禁提交任何真实密钥"
}
```

#### 第四步：首次启动与自检

```bash
# 启动开发服务器，控制台无红色报错才算成功
npm run dev

# 自检三件套：页面能打开、控制台无报错、健康检查接口通
```

启动失败按顺序排查：端口被占（换端口或结束占用进程）、依赖缺漏（重装）、环境文件缺项（对照示例补齐）。排查命令与完整清单见《高频故障排查手册》。

### 首次调试与会话建立

#### 把开发服务器跑在调试模式

不要只会 `console.log`：浏览器开发者工具里打断点、看网络面板的请求与响应、看错误面板的完整堆栈。后端项目在 IDE 里以调试模式启动，在关键方法入口打断点，观察入参的实际值——第一次「看见代码怎么跑」的时刻，比背十条语法都有用。

#### 熟悉门禁命令

进项目第一天就把门禁命令全部跑一遍，建立「绿了才提交」的肌肉记忆：

```bash
# 类型检查、测试、构建，三条命令全绿是提交的前提
npm run typecheck
npm test
npm run build
```

### 首个特性分支与首次修改

#### 按规范检出分支

```bash
# 同步主干后检出特性分支，命名遵循分支规范
git checkout main
git pull --rebase origin main
git checkout -b docs/first-contrib
```

#### 认领微型任务

首个任务从标注了「新人友好」的微型任务认领：改一处文案、补一个测试用例、修一个样式小缺陷。任务虽小，流程不减——分支、提交、门禁、评审一步不少。

```bash
# 原子提交：一个提交只做一件事，信息符合规范
git add docs/guide.md
git commit -m "docs(guide): 补充本地启动步骤说明"

# 推送前先跑门禁，红项就地修复
npm run typecheck && npm test
```

### 首个合并请求与避坑

#### 发起合并请求

推送分支后发起合并请求，描述按三要素填写：改动内容、改动原因、验证方式。第一个请求主动请高年级成员评审，把评审意见当成免费的一对一教学。

#### 新人高频翻车清单

| 症状 | 根因 | 修复方案 |
|---|---|---|
| 把 `.env.local` 提交进仓库 | 不了解忽略规则 | 检查忽略文件清单，已入库立即找师傅处理 |
| 直接在 `main` 上改了代码 | 分支习惯未建立 | 立即检出分支保存改动，主干恢复原状 |
| 提交里混着格式化噪音 | 保存格式化没对齐项目配置 | 按《开发环境与工具链配置指南》接好配置 |
| 门禁红了照样推 | 没跑门禁 | 推送前本地全绿，推送后盯流水线结果 |
| 报错截图只拍一行 | 提问姿势不对 | 给完整报错、复现步骤与已尝试方案 |

### 首周验收清单

| 项目 | 验收标准 |
|---|---|
| 环境就绪 | 项目本地启动成功，门禁命令全绿 |
| 调试能力 | 能独立打断点并讲清一次请求的完整路径 |
| 分支纪律 | 首个改动走特性分支，命名符合规范 |
| 合并请求 | 首个请求三要素齐备，评审意见全部销项 |
| 求助效率 | 至少完成一次符合姿势的提问并获得解答 |
