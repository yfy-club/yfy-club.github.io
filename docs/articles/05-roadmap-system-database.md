### Linux 用户权限与系统运维

熟练掌握 Linux 权限体系与常用运维命令：

```
权限三段位（rwx）：读(4)、写(2)、执行(1)
八进制组合：755 (所有者 rwx / 群组 r-x / 其他 r-x)
           644 (所有者 rw- / 群组 r-- / 其他 r--)
```

掌握基于 `systemd` 的后台服务管理机制，通过 `systemctl` 控制服务启动、停止、重载与开机自启；使用 `ps` 与 `top` 监控系统进程资源，结合 `curl` 与 `ss` 排查端口占用与网络连通性。

### 关系型数据库范式与表结构设计

掌握关系数据库设计三大范式：

* **第一范式（1NF）**：属性具有原子性，不可再拆分；
* **第二范式（2NF）**：消除非主属性对主键的部分依赖；
* **第三范式（3NF）**：消除非主属性对主键的传递依赖。

合理设计字段类型（如整数、定点数 `DECIMAL`、变长字符串 `VARCHAR`），关键业务字段标注非空约束并设定合理的默认值。

### 复杂 SQL 编写与事务 ACID 特性

熟练编写多表内连接（`INNER JOIN`）、左外连接（`LEFT JOIN`）以及嵌套子查询，灵活运用 `GROUP BY` 与 `HAVING` 过滤聚合统计结果。

深入理解数据库事务四大特性：原子性（Atomicity）、一致性（Consistency）、隔离性（Isolation）与持久性（Durability）。理解读未提交、读已提交、可重复读与串行化四种隔离级别，掌握脏读、不可重复读与幻读的产生机理与防范方案。

### B+ 树索引原理与慢查询优化

深入理解 MySQL InnoDB 存储引擎的 B+ 树索引结构：叶子节点通过双向链表串联，支持高效的高速点查与范围扫描。

区分聚簇索引（数据行直接存放在叶子节点）与二级索引（叶子节点存放主键值）。优先利用覆盖索引减少回表开销；通过 `EXPLAIN` 分析执行计划中的 `type`、`key` 与 `rows` 字段，精准定位索引失效与慢查询瓶颈。

### 参数化查询与安全防线

在数据访问层统一采用预编译语句（PreparedStatement）或参数化查询接口，严禁直接拼接 SQL 字符串，从架构根源彻底杜绝 SQL 注入漏洞。
