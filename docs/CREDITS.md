# 署名

本站自有内容（文案、代码）不需要外部署名。这份文件只用来登记**放进来的第三方素材**，
以及**生成式工具的产出**——后者不一定需要署名，但需要记录来源与授权依据，见「角色立绘」一节。

---

## BGM

暂无。`public/audio/` 是空的，页面上的声音开关处于隐藏状态。

放入曲目后，如果它的许可证要求署名，改两处：

1. 把下面这张表填上；
2. 把 `src/data/credits.ts` 的 `BGM_CREDIT` 从 `null` 改成一行字符串，格式 `BGM: 曲名 — 作者（来源站点 / 许可证）`。页脚会自动多出这一行。

| 曲名 | 作者 | 来源 | 许可证 | 下载日期 |
|---|---|---|---|---|
| —— | —— | —— | —— | —— |

音源渠道与筛选标准见 [music-sources.md](music-sources.md)，转码命令也在那里。
**游戏原声、扒站音频、来路不明的二创一律不要**，那一节写得很清楚。

## 角色立绘

`public/images/characters/` 的六张角色立绘由 **NovelAI 图像生成**产出，提示词与生成过程由本社团进行，
未使用任何现有作品的角色形象作参考图。原始 PNG 存在 `assets-src/characters/`（不进 `public/`，
那是 4.7 MB 无损原稿），上线产物由 `npm run portraits:build` 切成三档 WebP。

| 项 | 内容 |
|---|---|
| 工具 | NovelAI 图像生成 |
| 输入 | 本社团自行撰写的提示词，无参考图 |
| 用途 | 六位虚构角色的形象，见 `src/data/characters.ts` |
| 归属 | 依 NovelAI 服务条款，生成内容的权利归生成者所有；本站作商业性以外的社团展示用途 |

> 这一节不是可有可无的合规话术。规格 1.2「版权立场」原文写的是
> 「全部立绘为**本工程内原创矢量绘制**，无外部图源」——M8 之后这句话不再成立，
> 规格里已经改口（见 design-spec.md 的 M8 修正记录），这里记的是改口之后的事实依据。
>
> 1.2 真正要守住的那两条**没有变**：不使用任何现有作品的官方角色名、角色形象、Logo、
> 字体、音效、UI 素材；借鉴的只是设计语言。生成时没有喂参考图，这一点是前提。
