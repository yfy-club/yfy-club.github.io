# 合规 BGM / 音效 音源渠道清单

> 本工程**不自带任何第三方音频文件**。请你从下列渠道自行下载、自行确认授权条款，再放入 `public/audio/`。
> 各站条款会变动，**以你下载当天的页面条款为准**，下面的说明仅供筛选起点。

---

## 1. 优先推荐（日系氛围最贴合本站调性）

| 站点 | 地址 | 授权要点 | 备注 |
|---|---|---|---|
| **DOVA-SYNDROME** | `dova-s.jp` | 基本免费商用，但**逐曲以作曲者个人规约为准**（部分禁止特定用途、部分要求署名） | 日本最大免费 BGM 库，日系轻电子/环境曲储量最好。下载页务必点开「利用規約」看那位作者的条款 |
| **魔王魂** | `maou.audio` | 免费商用，**需按站方要求署名** | 曲风偏游戏化，与「观测站」设定契合 |
| **甘茶の音楽工房** | `amachamusic.chagasi.com` | 免费商用，署名非强制但推荐 | 空气感钢琴 / 治愈系，最接近京阿尼日常调性 |
| **OtoLogic** | `otologic.jp` | CC-BY 类，需署名 | 音效为主，也有短 BGM |

## 3. 明确不要用

- 游戏原声（碧蓝档案 / 原神 / 明日方舟 OST 等）——**绝对不行**，这是最容易惹麻烦的一类。
- 从网易云、QQ 音乐、B 站、YouTube 直接扒下来的音频。
- 东方 Project 等同人曲——各社团规约不同，除非你逐条确认过，否则不碰。
- 抖音热门 / ACG 二创 / Nightcore 版本。
- YouTube Audio Library：条款主要面向 YouTube 平台内使用，拿到自建网站上用存在灰色地带，不建议。

## 4. 曲目筛选建议

站点调性是「晴空 + 精密 HUD + 日常感」，BGM 需要**能被无视**——它是背景不是主角。

- 曲风：日系 lo-fi / 环境钢琴 / 轻电子 + 空气 pad
- BPM：70–90
- **无人声**（人声会抢文字阅读的注意力）
- 无强鼓点、无明显段落高潮
- 循环点自然（最好本身就是 loop 素材）
- 时长 1–3 分钟即可，靠循环撑

## 5. 落地技术要求

放入前请转码，控制体积：

```bash
# 主格式：Opus（体积最小，现代浏览器全支持）
ffmpeg -i 原曲.wav -c:a libopus -b:a 96k -vbr on public/audio/bgm.ogg

# 兜底格式：MP3（老 Safari）
ffmpeg -i 原曲.wav -c:a libmp3lame -b:a 128k public/audio/bgm.mp3
```

- 体积上限：**单文件 ≤ 2.5MB**（GitHub Pages 仓库有 1GB 软上限、月流量 100GB 软上限，且用户是移动网络）
- 文件名固定为 `bgm.ogg` / `bgm.mp3`，播放器按此路径查找
- **文件不存在时，页面上的声音开关会自动隐藏**，不会报错也不会留死按钮，所以你可以先不放

## 6. 署名落位

若选定曲目要求署名，写入两处：

1. `docs/CREDITS.md`
2. 页面页脚「音乐」一行，格式：`BGM: 曲名 — 作者（来源站点 / 许可证）`
